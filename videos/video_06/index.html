Building a Basic Web Server

What is routing?

“Routing determines how the server responds to different URLs.”
  • Based on data in the http.IncomingMessage.
  • URL: protocol, subdomain, root domain, slug, query parameters
  • METHOD: get, post, put, patch, delete
  • HEADERS: accept type

URL Example

Simple Routing


// http_url_routing.js

const http = require("http");

const server = http.createServer((req, res) => {
    res.setHeader("Content-Type", "text/plain");

    switch (req.url) {
        case "/":
            res.end("Welcome to the homepage!");
            break;
        case "/about":
            res.end("This is the about page.");
            break;
        case "/contact":
            res.end("Contact us at contact@example.com");
            break;
        default:
            res.statusCode = 404;
            res.end("Page not found");
    }
});

server.listen(3000, () => {
    console.log("Server running at http://localhost:3000/");
});
        

// terminal window
node http_url_routing.js

URL Example

Data Response


// http_header_routing.js
const http = require('http');

const person = {
    first: "Jane",
    last: "Doe",
    email: "jane.doe@example.com"
};

const server = http.createServer((req, res) => {
    const acceptHeader = req.headers['accept'];

    if (acceptHeader && acceptHeader.includes('application/json')) {
        // JSON response
        res.writeHead(200, { 'Content-Type': 'application/json' });
        res.end(JSON.stringify(person, null, 2));
    } else {
        // HTML response
        res.writeHead(200, { 'Content-Type': 'text/html' });
        res.end(`...HTML RESPONSE...`);
    }
});

server.listen(3000, () => {
    console.log(`Server running at http://localhost:3000`);
});
        

// terminal window
node http_header_routing.js

Key Takeaways

  • Basic routing is manual but great for learning.
  • Routes can be extended for HTML, JSON, or dynamic content.
  • Sets the foundation for templating and MVC structure later.
