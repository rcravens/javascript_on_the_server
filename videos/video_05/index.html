The HTTP Module

Building a Basic Web Server

Why the HTTP Module?

  • Node provides the core HTTP module - no extra packages needed.
  • Allows you to listen for incoming requests and respond with data.
  • Foundation for building web servers, APIs, and dynamic websites.
Learn More

Web Foundations

  • HTTP (Hyper Text Transport Protocol) is the language between browsers (clients) and servers.
  • Request and Response Cycle:
    • You open your browser, the Client, and type in a web address like https://tekcasts.com and hit enter.
    • The browser takes this address and builds an HTTP Request.
    • After some networking (DNS, routing, TLS/SSL, ...) the server receives the HTTP Request.
    • The server generates an HTTP Response to that request.
    • After some networking the browser receives the HTTP Response.
    • The browser parses the HTTP Response and renders the requested page.

Minimal HTTP Server

Using the HTTP Module


// http_min.js

const http = require("http"); // CommonJS

const server = http.createServer((req, res) => {
  res.statusCode = 200;
  res.setHeader("Content-Type", "text/plain");
  res.end("Hello World\n");
});

server.listen(3000, () => {
  console.log("Server running at http://localhost:3000/");
});
        

// terminal window
> node http_min.js
> Server running at http://localhost:3000/
> ^C

The Request

Deeper Look

http.IncomingMessage object (i.e. req) contains the request info.

Learn More 

// most used
req.url                     // /api/v1/users
req.method                  // GET, POST
req.headers                 // object with **ALL** headers
req.headers['user-agent']   // value of a single header

The Response

Deeper Look

http.ServerResponse object (i.e. res) contains methods to set the response headers and body.

Learn More 

// most used
res.statusCode = val            // set the response HTTP status code (e.g., 200, 404)
res.setHeader(key, val)         // set the specified header
res.writeHead(status, object)   // sends status & response headers to client
res.write(data)                 // sends text, stream, or chunk to the client
res.end(data)                   // sends final text, and signals that the response is complete

Key Takeaways

  • The HTTP module is minimal but powerful.
  • Even without frameworks, you can serve static or dynamic content.
  • Sets the stage for routing, serving HTML, and building web apps.
