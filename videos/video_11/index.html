Dynamic Web Pages (SSR with Templates)

Why Templates?

Static HTML -vs- Server-Side Rendering (SSR)

  • Static HTML:
    • 👉 Pages are pre-written and don't change based on data.
    • 👉 Easy to serve but not interactive with live data.
  • Sever-Side Rendering (SSR):
    • 👉 HTML is generated on the server using data before sending to the client.
    • 👉 Enables personalized content, dynamic lists, and database-driven pages.

Benefits of Dynamic Content

  • Content updates without changing the HTML files manually.
  • Centralized data source (e.g., database, JSON files).
  • Reusable components with templates.
  • Easier to maintain as the app grows.

Manual Templating

Simple Example


// server.json (partial)
function render_page(users) {
    let table = `
<html lang="en">
  <head>...HEAD CONTENT...</head>
  <body>
    <h1 style="text-align:center;">Users</h1>
    <table>
      <tr><th>First Name</th><th>Last Name</th><th>Email</th></tr>
  `;

    for (const user of users) {
      table += `
        <tr>
          <td>${user.first_name}</td>
          <td>${user.last_name}</td>
          <td>${user.email}</td>
        </tr>
    `;
    }

    table += `
    </table>
  </body>
</html>
  `;

    return table;
}

Server-Side Rendering

Simple Example


// server.js (partial)

// Create HTTP server
const server = http.createServer(async (req, res) => {
    if (req.url === "/users") {
        const users = await User.all();
        const html = render_page(users);

        res.writeHead(200, { "Content-Type": "text/html" });
        res.end(html);
    } else {
        res.writeHead(404, { "Content-Type": "text/plain" });
        res.end("Not Found");
    }
});

// Start server
const PORT = 3000;
server.listen(PORT, () => {
    console.log(`Server running at http://localhost:${PORT}/users`);
});
        

// terminal window
node server.js

Manual Templating Drawbacks

Simple Example

  • Hard to maintain for complex layouts.
  • Mixing HTML and JS logic gets messy quickly.
  • Reusability is difficult (no partials / layouts / components).

Key Takeaways

  • Templates separate data from layout.
  • Avoid manual string concatenation for readability and maintainability.
