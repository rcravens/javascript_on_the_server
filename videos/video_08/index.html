What is a JSON API?

  • JSON = JavaScript Object Notation.
  • APIs expose data over HTTP for applications to consume.
  • 👉 Front-end apps requesting data (fetch, Axios).
  • 👉 Mobile apps consuming backend data.
  • 👉 Microservices communicating via JSON.

Returning JSON Data

Simple Example


// http_return_json.js
const http = require("http");

const server = http.createServer((req, res) => {
  if (req.url === "/api") {
    res.setHeader("Content-Type", "application/json");
    const data = { message: "Hello from API", timestamp: Date.now() };
    res.end(JSON.stringify(data));
  } else {
    res.statusCode = 404;
    res.end("Not Found");
  }
});

server.listen(3000, () => {
  console.log("Server running at http://localhost:3000/");
});
        

// terminal window
node http_return_json.js

Parsing JSON Request Body

Simple Example


// http_parse_json.js (partial)
if (req.method === "POST") {
    let body = "";
    req.on("data", chunk => {
        body += chunk;
    });
    req.on("end", () => {
        const parsed = JSON.parse(body);
        console.log("Received data:", parsed);
        res.setHeader("Content-Type", "application/json");
        res.end(JSON.stringify({ status: "ok", received: parsed }));
    });
} else {
    res.setHeader("Content-Type", "application/json");
    const data = {message: "Hello from API", timestamp: Date.now()};
    res.end(JSON.stringify(data));
}
        

// terminal window
node http_parse_json.js

Key Takeaways

  • APIs are core to modern web apps.
  • Correct Content-Type ensures clients parse data correctly.
  • Streaming data allows handling large payloads efficiently.
