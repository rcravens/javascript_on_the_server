Beyond the Basics

Our Framework

  • Router provides semantic / developer friendly registration options.
  • Middleware system provides a clean way to interject logic on any request / response.
  • MVC creates architectural organization and encourages separation of concerns.
  • BaseController enables writing "slim" controllers with common responses.
  • BaseModel provides "out-of-the-box" CRUD methods to any model class.
  • Validator allows for easy validation of user provided data.
  • SessionManager enhances request/responses by adding state to HTTP.
  • View Helpers empower dynamic views based on session data.

Final Refactors

  • BaseController - move to app directory.
  • BaseModel - move to app directory.
  • Router - feed body data to middleware.
  • Router - handle static files (images, css, script).
  • Encapsulation - minimize public footprint.
  • Single Responsibility - refactor files until each has a single responsibility.
  • DRY - "don't repeat yourself" - look for duplicate code.
  • Coding Style - write code in a consistent style (e.g., spacing, casing,...etc).
