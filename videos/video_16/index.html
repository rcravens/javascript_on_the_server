Why Cookies?

  • HTTP is stateless: each request is independent.
  • Cookies / Cookie Data:
    • 👉 Stored by your web browser (client side).
    • 👉 Data is available on both the client (only non "HTTP Only") & server.
    • 👉 Travel in the request / response headers: server --> client --> server.
    • 👉 Allow servers to remember clients across requests.
    • 👉 Can originate on the client or the server.
    • 👉 Small pieces of information.
    • 👉 Usage: session ID, personalization, tracking/analytics...

Cookie Storage


// server.js (partial)

// Cookie Data - Example: "Name1=Value1; Name2=Value2;..."
console.log(req.headers.cookie);

// Cookie Parser
parseCookies(req) {
    const list = {};
    const cookieHeader = req.headers.cookie || "";
    cookieHeader.split(";").forEach(cookie => {
        const parts = cookie.split("=");
        if (parts.length === 2) list[parts[0].trim()] = decodeURIComponent(parts[1].trim());
    });
    return list;
}

// Set and clear cookie data from the server
res.setHeader("Set-Cookie", [
        `COOKIE1=Chocolate Chip; HttpOnly; Path=/`,                 // set cookie
        `COOKIE2=Oatmeal Raisin; HttpOnly; Path=/; Max-Age=10`,     // set another cookie (10s)
        `SID=; HttpOnly; Path=/; Max-Age=0`                         // clear a cookie
    ]
);
        

// terminal

npm run dev

Key Takeaways

  • Cookies store client-side data.
  • Production Considerations:
    • 👉 Use signed/encrypted cookies.
    • 👉 Be careful of what you store in cookies.
