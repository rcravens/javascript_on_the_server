Basic Consideration

Node in Production

  • node server.js is fine for development, but not robust for production.
  • Risks:
    • 👉 App crashes stop the server.
    • 👉 No automatic restarts on errors or system reboot.
    • 👉 Logs and process monitoring are manual.

Process Managers

Node in Production

  • Process managers monitor app and restarts if issues occur.
  • PM2 is a popular Node process manager.
  • Features:
    • 👉 Automatic restarts on crashes.
    • 👉 Load balancing across multiple CPU cores.
    • 👉 Easy log management.
    • 👉 Startup scripts for server reboot.

PM2 Installation


// terminal
npm install -g pm2          // installed globally

pm2 --version               // get installed version

Environment Variables

Node in Production

  • Use .env or system environment variables to avoid hardcoding secrets or ports.

// terminal
npm install dotenv
        

// .env
PORT=3001
NODE_ENV=production
SESSION_SECRET=mySecretKey
        

// app/server.js (partial)

import dotenv from "dotenv";

dotenv.config();
const PORT = process.env.PORT || 3000;

            ...

server.listen(PORT, () => {
    console.log(`Server running at http://localhost:${PORT}/users`);
});
