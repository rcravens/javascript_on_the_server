Using EJS Templates

Module

Dynamic Web Pages (SSR with Templates)

What is EJS

EJS = Embedded JavaScript

  • Templating engine that allows embedding JavaScript into HTML.
  • Server-side rendering of HTML with dynamic data.
  • Separates layout and data logic, improving maintainability.

Installing EJS


// terminal window

npm init -y             // initialize project

npm install ejs         // install dependency

EJS Syntax


<%= user.last_name %>             --> outputs escaped value (HTML-escaped)
<%- user.last_name %>             --> outputs unescaped raw HTML
<% users.forEach(user => { %>     --> executes JS without output (for loops, conditionals...)

EJS Rendering

Full Page Example


// views/users.ejs

<!DOCTYPE html>
<html lang="en">
<head>
    <title>Users</title>
    <style>
        table { border-collapse: collapse; width: 50%; margin: 20px auto; }
        th, td { border: 1px solid #ccc; padding: 8px; text-align: left; }
        th { background-color: #f4f4f4; }
    </style>
</head>
<body>
<h1 style="text-align:center;">Users</h1>
<table>
    <tr>
        <th>First Name</th>
        <th>Last Name</th>
        <th>Email</th>
    </tr>
    <% users.forEach(user => { %>
        <tr>
            <td><%= user.first_name %></td>
            <td><%= user.last_name %></td>
            <td><%= user.email %></td>
        </tr>
    <% }) %>
</table>
</body>
</html>

Router

Full Page Example


// server.js (partial)

const server = http.createServer(async (req, res) => {
    if (req.url === "/users") {
        const users = await User.all();

        try {
            const html = await ejs.renderFile("views/users.ejs", {users});
            res.writeHead(200, {"Content-Type": "text/html"});
            res.end(html);
        } catch (err) {
            res.writeHead(500, {"Content-Type": "text/plain"});
            res.end("Error rendering template");
            console.error("EJS render error:", err);
        }
    }
});
        

// terminal
node server.js
http://localhost:3000/users

EJS Layouts & Partials

Layout Example


// layout.js (layout)

<!DOCTYPE html>
<html lang="en">
<%- include("_head") %>
<body>
  <%- body %>
</body>
</html>
        

// _head.js (partial)

<head>
    <title>Users</title>

Router

Layout Example


// server.js (partial)

const server = http.createServer(async (req, res) => {
    if(req.url === "/users2") {
        const users = await User.all();

        // Render page content
        const content = await ejs.renderFile("views/users2.ejs", { users });

        // Render layout with content injected as `body`
        const html = await ejs.renderFile("views/layouts/layout.ejs", { body: content });

        res.writeHead(200, { "Content-Type": "text/html" });
        res.end(html);
    }
});
        

// terminal
node server.js
http://localhost:3000/users2

Key Takeaways

  • EJS simplifies dynamic HTML generation.
  • Avoid manual string concatenation for readability and maintainability.
  • Build reusable layouts and partials.
