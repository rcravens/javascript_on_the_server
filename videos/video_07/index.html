Building a Basic Web Server

Why Serve Static Files?

  • Users expect styled web pages, not plain text.
  • HTML provides structure, CSS provides style, JS provides interactivity.
  • Node can server any file type (text, image, JSON, etc.) using the fs module.

Basic File Server

Using the HTTP Module


// http_static.js (partial)

http.createServer(async (req, res) => {
        const file = await prepareFile(req.url);
        const statusCode = file.found ? 200 : 404;
        const mimeType = MIME_TYPES[file.ext] || MIME_TYPES.default;
        res.writeHead(statusCode, { "Content-Type": mimeType });
        file.stream.pipe(res);
        console.log(`${req.method} ${req.url} ${statusCode}`);
    });
        

// terminal window
node http_static.js

Key Takeaways

  • Node can server any file type with the correct Content-Type header.
  • Async file reading ensures the server doesn't block while sending files.
  • This is a stepping stone for templating and dynamic content.
