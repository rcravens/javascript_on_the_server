HTML Forms

Visitors Send Data To Server

  • Client Side - HTML Form:
    • 👉 Forms allow user to enter and submit data to the server.
    • 👉 Set the HTTP verb / method: method="POST".
    • 👉 Set the end-point: action="/users".
    • 👉 Provide input, textarea, and other elements for data entry.
    • 👉 Data is included in the request data submitted to the server.
  • Server Side - Request / Response:
    • 👉 Node streams incoming data as part of the request.
    • 👉 Parse data into a usable form.
    • 👉 List for "data" and "end" events.

Other Considerations

  • Sanitization:
    • 👉 Performed at "point of use".
    • 👉 Prevents XSS and injection attacks.
    • 👉 EJS example: <%= variable %> performs HTML sanitization, <%- variable %> DOES NOT.
    • 👉 SQL: use "parameterized queries" to sanitize variables used in queries.
  • Validation:
    • 👉 Performed immediately...before storing or using any data.
    • 👉 Inspection to ensure data conforms to predefined rules (length, min/max, email...).
    • 👉 Data that fails inspection should be sent back to browser for the user to edit.

Validation Rules

Simple Validation


// models/User.js

import { BaseModel } from "./BaseModel.js";

export default class User extends BaseModel {
    static fileName = "users.json";  // JSON file inside /data
    static keyField = "email";       // unique identifier

    static rules = {
        first_name: { required: true, type: "string", min: 2, max: 50 },
        last_name:  { required: true, type: "string", min: 2, max: 50 },
        email:      { required: true, type: "string", pattern: /^[^\s@]+@[^\s@]+\.[^\s@]+$/ }
    };

    constructor(first_name, last_name, email) {
        super();
        this.first_name = first_name;
        this.last_name = last_name;
        this.email = email;
    }
}

// Validator.js (partial)

export default class Validator {
    static validate(rules, data) {
        const errors = {};

        for (const [field, rule] of Object.entries(rules)) {
            const value = data[field];

            // Check required
            if (rule.required && (value === undefined || value === null || value === "")) {
                errors[field] = `${field} is required`;
                continue;
            }

            if (value == null) continue; // skip further checks if value is optional & missing

            // Min length
            if (rule.min && typeof value === "string" && value.length < rule.min) {
                errors[field] = `${field} must be at least ${rule.min} characters`;
            }

            ... OTHER VALIDATION CHECKS ...
        }

        return {
            valid: Object.keys(errors).length === 0,
            errors,
        };
    }
}
